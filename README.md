# Aventura Nacional — Videoclip oficial

Repositorio de producción del videoclip ilustrado de **Aventura Nacional**.

## Objetivo
Crear un videoclip completo en formato 16:9 mediante imágenes consistentes, frases y letras sincronizadas en CapCut Pro.

## Estructura
- `docs/` — Biblia visual, continuidad y decisiones creativas.
- `storyboard/` — Desglose narrativo y técnico por escenas.
- `prompts/` — Prompts definitivos para generar cada imagen.
- `assets/images/` — Imágenes finales numeradas.
- `assets/references/` — Hojas de personaje, bus, ciudad y referencias.
- `capcut/` — Guía de montaje, textos, efectos y transiciones.

## Convención de archivos
Las imágenes conservarán este formato:

`AN_001_intro_cinco_minutitos.png`

`AN_002_cinco_alarmas.png`

Esto permitirá ordenarlas automáticamente en CapCut.
